# 佩佩動態工具包

做銷售頁、廣告動態用的兩樣工具，Windows 用。

## 怎麼下載

按右上角綠色的 **Code → Download ZIP**，解壓縮就好。

---

## 1. PS 動態面板（Photoshop 擴充）

裝一次會有兩個面板：

| 面板 | 用來做什麼 |
|---|---|
| **佩佩動態前綴** | 幫圖層或工作區域加上「動-飄浮」「動-流光」這類名字，給下面的動態小工具讀 |
| **佩佩PS動畫** | 在 PS 裡直接做動畫 GIF：選圖層按效果，再一鍵輸出；也有一鍵 PDF／PNG、逐格 GIF、參考線切圖 |

**安裝**
1. 打開 `PS動態面板` 資料夾，雙擊 `安裝面板.bat`
2. 把 Photoshop 完全關掉再打開
3. 到「視窗 > 擴充功能」，就會看到「佩佩動態前綴」和「佩佩PS動畫」

支援 Photoshop 2020 以後的版本（CEP 擴充）。

---

## 2. 動態小工具（電腦上的小軟體）

把 PSD 拖進去，它看圖層名稱就知道哪一層要動，直接輸出 MP4 或 GIF。

**要先裝**
- Python 3.10 以上（安裝時勾選「Add Python to PATH」）
- ffmpeg（要能在命令列打 `ffmpeg` 執行）

**安裝**
1. 打開 `動態小工具` 資料夾，雙擊 `安裝套件.bat`（只要第一次）
2. 之後雙擊 `啟動.bat`，瀏覽器會自己打開小工具
3. 把 PSD 拖進去，預覽好之後按輸出，檔案會存在 PSD 旁邊的「輸出」資料夾

**圖層要怎麼取名**
在圖層名稱前面加 `動-` 再接效果，例如：
- `動-飄浮 商品`：上下飄
- `動-搖擺 圓章`：左右擺
- `動-流光 主標`：一道光掃過
- 可以疊加：`動-飄浮-流光 商品`

用上面的「佩佩動態前綴」面板按一下就能加，不用自己打。
